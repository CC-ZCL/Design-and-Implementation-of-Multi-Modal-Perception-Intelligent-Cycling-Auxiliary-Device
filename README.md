# MultiCheck 多模态感知智能骑行辅助设备
## 项目简介
随着绿色出行理念普及，骑行出行日益增多，但道路骑行安全隐患突出。传统骑行辅助设备智能化不足，难以满足现代骑行安全防护需求。本项目设计一套**基于树莓派4B的多模态感知智能骑行辅助设备**，结合ESP32辅助单片机、多种传感器、目标检测与多模态大模型，实现骑行环境感知、障碍物预警、自动灯光、云端远程监控等功能，提升骑行安全。

## 目录结构
```
MultiCheck/
├── .git/                # Git版本管理目录
├── logs/                # 运行日志存放目录
├── multimod_app/        # 业务应用代码目录(PyQt5界面、模型调用、云通信等)
└── main.py              # 项目主入口文件
```

## 硬件清单
- 主控：树莓派4B
- 辅助控制器：ESP32‑S3单片机
- 传感器：摄像头、DHT11温湿度传感器、光照传感器、HC‑SR04超声波测距、红外测速模块
- 外设：OLED显示屏、MOS管灯光控制模块、蜂鸣器预警模块

## 主要功能
1. 环境与运动状态采集：采集温湿度、光照、距离、骑行速度等传感数据
2. 道路目标检测：YOLOv8实现道路障碍物、行人目标检测
3. 多模态融合分析：调用qwen3_vl_plus模型融合视觉图像与传感器数据
4. 本地交互终端：基于PyQt5构建可视化本地界面，实时展示采集数据
5. 第三方天气接口对接，获取实时气象信息
6. 阿里云IoT平台MQTT通信：数据上传，支持手机APP远程监控
7. 业务功能：障碍物声光预警、自动灯光控制、OLED本地数据显示

## 环境依赖
> 建议在树莓派Python3环境运行
```bash
pip install ultralytics
pip install pyqt5
pip install paho-mqtt
pip install requests
# 以及串口通信、qwen3_vl_plus模型SDK相关依赖
```

## 运行方式
1. 将项目全部文件拷贝至树莓派本地
2. 根据实际硬件修改串口、阿里云IoT设备参数、模型调用配置
3. 安装全部python依赖包
4. 启动主程序
```bash
python main.py
```

本系统针对骑行安全场景，实现多维度感知防护，具备良好实际使用价值，可用于骑行安全辅助，拥有不错的推广前景。

## 注意事项
1. 使用前确认ESP32串口端口号正确，避免串口打开失败
2. 使用阿里云IoT，需要自行配置设备证书、MQTT连接参数
3. qwen3_vl_plus调用需要配置对应的API密钥
4. logs文件夹会自动生成运行日志，便于调试排错
